# 03 · Find a new place to look.

**For sourcers + hiring teams** · About 5 min

> **Use it when:** Every search returns the same profiles. Same work often hides under a different title.  
> **Have ready:** Outcomes, must-haves, titles you already search

## Copy this

```text
Suggest three adjacent job titles or backgrounds worth researching for this role.

For each one, give me:
1. The work that could overlap with what we need.
2. The evidence I should look for to confirm it.
3. One question to test that overlap in a conversation.

These are search ideas, not judgments about anyone's ability. Keep every non-negotiable. Do not name people or assume a title proves a skill. Under 250 words.

OUTCOMES WE NEED: [paste]
NON-NEGOTIABLES: [paste]
TITLES WE ALREADY SEARCH: [paste]
```

Swap every `[bracketed]` part for your own details.

## Made-up example

**You paste:** “Ship LLM features to production: retrieval and evals. Must have shipped an LLM feature real users rely on. We search: Machine Learning Engineer.”

**One idea it might give you:**

Search or backend engineers who built retrieval systems. Check they shipped to production. A weekend RAG demo does not prove it.

## Then do this

- [ ] Try one new title this week
- [ ] Look for the evidence, not the title
- [ ] Ask the test question on the first call
