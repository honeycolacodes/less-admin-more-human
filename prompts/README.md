## Quick fixes when an answer misses

- **Too generic.** Add one real constraint. “The team has no dedicated infrastructure engineer” beats “we are a fast-moving startup.”

- **Sounds like a robot.** Reply with: `Rewrite this the way I would say it out loud. Shorter sentences.`
